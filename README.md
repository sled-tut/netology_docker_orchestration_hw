Предупреждение возникает из-за того, что ранее запущенный контейнер task5-portainer-1 после удаления compose.yaml остаётся сиротой ("orphan"), поскольку именно этот сервис был описан в удаленном файле (но он пока продолжает работать, как можно видеть в результате ```docker ps -a```). По сути он принадлежит старому проекту, а мы сейчас пытаемся запустить новый одноимённый (имя проекта негласно берётся от названия самой директории, где он запускается), где этого сервиса уже нет.
Поскольку сервис удалили из компоуз-файла (вместе с самим файлом), команду ```docker compose up``` следует запускать со следующим параметром, тогда существующий контейнер будет удалён при старте проекта:
```
docker compose up -d --remove-orphans
```
Команда, чтобы погасить проект целиком (останавливает и удаляет все контейнеры, удаляет сети, если они были описаны, и другие ресурсы):
```
docker compose down
```

compose.yaml
```
version: "3"
include:
  - docker-compose.yaml
services:
  portainer:
    network_mode: host
    image: portainer/portainer-ce:latest
    depends_on: registry
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
```
