Проблема в том, что когда мы перенаправляем ввод в контейнер, сигнал Ctrl-C (сигнал прерывания) получается основной процесс контейнера, работающий в foreground-режиме, вследствие чего завершает свою работу.

А в случае смены порта в конфиге nginx возникает конфликт: ранее мы из терминала запускали контейнер, явно прописывая какой порт контейнера пробросить в порт 8080 основного хоста. Поэтому после наших изменений контейнер теперь "слушает" порт 81, а основной хост все ещё перенаправляет наш запрос на порт 8080 - на порт 80, который в контейнере теперь закрыт.
